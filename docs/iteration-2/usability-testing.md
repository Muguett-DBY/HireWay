# Iteration 2 usability testing

Iteration 2 usability work combined a heuristic walkthrough of every page
with unmoderated task observations, and it set the baseline for the
moderated sessions planned with classmates next iteration.

## Method

- Heuristic walkthrough against the Nielsen set (visibility of status,
  match with the real world, user control, consistency, error prevention,
  recognition, flexibility, aesthetics).
- Task observations: three new users each completed create profile, add
  two skills, plan a target role, read the analysis page and set a skill
  to Completed. Sessions ran on the deployed site with the think-aloud
  protocol.
- Findings were rated on severity: 3 blocks the task, 2 causes hesitation,
  1 is cosmetic.

## Findings

| Severity | Finding                                                                                                                         | Outcome                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 2        | The study search box requires picking a suggestion; two participants typed a full course name and pressed Enter with no effect. | Help text now says to pick a suggestion; keep and consider an inline hint on Enter.       |
| 2        | "Improve" versus "Missing" was not obvious the first time a user saw the gap buckets.                                           | Labels now read as plain sentences with counts, and the evidence tag explains the source. |
| 1        | The status pills on My skills were not recognised as clickable until hovered.                                                   | Pills now fill with colour in their active state.                                         |
| 1        | Users wanted the readiness number explained.                                                                                    | The caption names it as coverage of the catalogue entry, not a hiring prediction.         |

No severity 3 issues remain open.

## Planned for next iteration

Moderated sessions with five students from outside the team, adding two
tasks for the progress tracker (plan a skill, mark it completed) and one
comprehension question on the readiness score.
